# AI PDF Assistant 🤖📄

A local Generative AI application that allows users to chat with PDF documents.

## Features
- Extract text from PDF
- Ask questions about document
- Runs fully locally using Ollama (no API cost)

## Tech Stack
- Python
- PyPDF
- Ollama (LLaMA 3)
- Requests

## How it works
1. Extract text from PDF
2. Send context + question to AI
3. Generate answer

## Run

```bash
python app.py
